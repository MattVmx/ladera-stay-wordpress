# Ladera Stay

Ladera Stay is a fictional lodging brand inspired by Patagonia. The project explores a calm, visual booking experience while keeping the content easy to manage from WordPress.

[Open the live WordPress demo](https://playground.wordpress.net/#%7B%22%24schema%22%3A%22https%3A%2F%2Fplayground.wordpress.net%2Fblueprint-schema.json%22%2C%22preferredVersions%22%3A%7B%22php%22%3A%228.3%22%2C%22wp%22%3A%22latest%22%7D%2C%22landingPage%22%3A%22%2F%22%2C%22login%22%3Atrue%2C%22steps%22%3A%5B%7B%22step%22%3A%22installTheme%22%2C%22themeData%22%3A%7B%22resource%22%3A%22git%3Adirectory%22%2C%22url%22%3A%22https%3A%2F%2Fgithub.com%2FMattVmx%2Fladera-stay-wordpress%22%2C%22ref%22%3A%22main%22%2C%22path%22%3A%22%2F%22%7D%2C%22options%22%3A%7B%22activate%22%3Atrue%7D%7D%5D%7D)

## What's inside

- A custom WordPress theme built without a page builder
- Stays that can be added and edited from the dashboard
- An inquiry form that validates and stores submissions in WordPress
- Spanish and English content
- Light and dark themes that remember the visitor's preference
- Responsive layouts, keyboard-friendly navigation and accessible details
- Sample content added automatically so the demo is ready to explore

## Run it locally

You need Node.js 20.18 or newer. From this directory, run:

```bash
npx @wp-playground/cli@latest start
```

WordPress Playground will launch WordPress, mount the theme and activate it automatically. No paid hosting is required.
