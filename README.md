# Ladera Stay

Custom WordPress theme for a fictional nature-stay brand. Created as a portfolio project by Matías Speroni.

[Open the live WordPress demo](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/MattVmx/ladera-stay-wordpress/main/blueprint.json)

## What it demonstrates

- Custom WordPress theme development without a page builder
- Editable accommodation content through a custom post type
- Inquiry form that validates submissions and stores them in the WordPress dashboard
- Spanish/English content switcher and persistent light/dark theme preferences
- Responsive, accessible layouts and mobile navigation
- Archive and single templates for accommodation records
- Theme activation seed data for a ready-to-review demo

## Local preview

Requires Node.js 20.18 or newer. From this directory:

```bash
npx @wp-playground/cli@latest start
```

WordPress Playground automatically mounts and activates the theme. The demo runs locally and does not require paid hosting.
